# MLHC2026-Human-AI-Deferral
Code for the MLHC 2026 paper "Human–AI Deferral under Limited Expert Availability." Implements Learning to Augment (L2A), a soft-deferral method that blends novice and AI predictions to detect cerebral ischemia during carotid endarterectomy from cEEG, plus deferral baselines and analysis.
